This is the site you're on now! Here's some info on how I built it:

Backend:

This is a Go server using the standard library http package. It is currently running as a file server. I figured this is a case of keep it simple, stupid. Some background on why I chose Go: Originally I wanted to build this site using SvelteKit. I set up the project, ran sv to set up the barebones template, and it installed a MASSIVE amount of packages. Honestly it's just overkill for what I intend this site to be. On top of that, having that many packages installed as dependencies just opens up more security risks as well. I like knowing that all of the code running this server is out of the standard Go library, especially with all of the recent supply chain attacks on npm.

Frontend

This is about as simple as it can can get. I'm using good ole HTML + CSS.

Hosting/Architecture

This is where it gets a bit more interesting. This site is currently running on a Raspberry Pi 5 sitting on my desk. I'm using a Cloudflared tunnel to redirect traffic from Cloudflare directly to my Pi. The Cloudflare tunnel process running on the Pi then forwards the packets to a Docker container which contains the site itself.

Deployment

The code for this site is on Github here. For any changes, I commit those changes to Github. Afterwards, a task fires off which then builds a new Docker image of the site. Every time my Raspberry Pi reboots, it will pull the most recent Docker image of my site and start an instance of it.
